② 먼저 등록 데이터를 복사하세요
  1. GitHub 화면 오른쪽의 Run workflow를 누릅니다.
  2. 등록 데이터 칸에 [{로 시작하고 }]로 끝나는 JSON 전체를 붙여넣습니다. 네이버 URL만 붙여넣으면 등록되지 않습니다.
  3. 초록색 Run workflow 버튼을 누르면 자동 조회·중복 검사 후 사이트에 반영됩니다.

기존 식당 검색

전체 목록을 CSV로 내려받아 엑셀에서 수정한 뒤 다시 올리거나, 식당을 검색해 1개씩 수정할 수 있습니다. 원본 목록은 보호하고 변경한 식당만 별도로 저장합니다.

전체 목록 Excel(CSV) 수정

수정 내용 확인 및 반영

② 먼저 수정 데이터를 복사하세요
  1. GitHub 화면 오른쪽의 Run workflow를 누릅니다.
  2. 수정 데이터 칸에 복사한 JSON 전체를 붙여넣습니다.
  3. 초록색 Run workflow 버튼을 누르면 기존 식당 정보가 수정됩니다. 여러 묶음이면 묶음별로 이 과정을 반복합니다.
